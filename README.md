# 📱 アレルギー成分分析アプリ

## 1. プロジェクト概要

ユーザーが加工食品の成分表を撮影すると、  
該当製品に含まれる**アレルギー誘発成分を分析し、ユーザーに提供するAndroidアプリケーション**です。

また、ユーザーが自身のアレルギー成分を事前に登録することで、  
製品の分析結果と比較し、該当成分の含有有無を判断した上で、  
**危険性をユーザーに通知する機能**を備えています。

---

## 2. 開発背景

食品を購入する際、以下のような問題があると考えました。

- 成分表の確認が煩雑で、可読性が低い  
- アレルギー成分を即座に把握することが難しい  

このような問題により、  
ユーザーが安全に食品を選択することが難しい状況があると判断しました。

---

## 3. 問題点

OCR機能を用いてテキストを抽出する過程において、  
**認識精度が低く、正確な商品名を取得できない問題**が発生しました。

そのため、単純な文字列比較では  
正確な製品マッチングが困難でした。

---

## 4. 解決方法

- 文字列類似度アルゴリズム（Jaro-Winkler）を活用し、商品名をマッチング  
- データベースに保存されたアレルギー情報を基に結果を提供  

これにより、OCRの認識誤りが発生した場合でも、  
**最も類似した製品を特定し、精度を補完する構造**を実現しました。

---

## 5. 主な機能

- 製品の撮影およびテキスト認識  
- アレルギー成分の分析  
- ユーザー登録および情報管理  

---

## 6. 担当役割

### 1) データベース設計および管理
- SQLiteを用いたDB構造の設計  
- 製品情報およびアレルギー成分データの管理  
- データ取得および処理ロジックの実装  

### 2) ユーザー登録機能の実装
- ユーザー情報保存のためのDB構造設計  
- ユーザー登録およびデータ保存機能の実装  

### 3) データ連携の構築
- 製品データとアレルギーデータを連携し、  
  機能が正常に動作するよう構造を設計  

---
